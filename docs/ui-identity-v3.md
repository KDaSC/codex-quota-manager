# 任务管家外观与导航 v3

用户要求：项目内聊天可折叠；有草稿的聊天置顶；参考成熟桌面产品改善外观；提供有辨识度的花形应用图标，并授权自行分配任务。

采用原生 SwiftUI，无新增界面依赖。信息结构参考 [Linear 个性化侧栏](https://linear.app/changelog/2024-12-18-personalized-sidebar)、[Raycast v2](https://manual.raycast.com/new-in-v2) 和 [Pearcleaner](https://github.com/alienator88/Pearcleaner#screenshots) 的侧栏层级、紧凑行和原生分栏，不复刻其品牌。

- 顶部独立“草稿置顶”快捷区；同一聊天仍保留在原项目中，避免项目内容缺失。
- 项目使用 DisclosureGroup，保存折叠状态；每个项目内部也将草稿排在前面。支持全部展开/折叠。
- 搜索时默认展开命中的项目，清除搜索恢复之前的折叠状态；搜索期间仍可手动折叠结果。
- 深青绿强调色、暖白画布、杏色草稿提示；深色跟随系统，保留对比度和减少动态效果设置。
- 原创五瓣花图标使用 AppKit/CoreGraphics 路径生成，深青绿圆角底、暖杏花瓣；不复制 Claude 的放射形商标。标准 ICNS 与窗口图标共享 PNG。

验收：实际点击项目折叠、搜索展开、重启保持、草稿置顶与选择详情；三页切换；编译与既有回归；解压包的图标元数据和签名。调度模型、阈值、权限、队列和发送路径不变。
