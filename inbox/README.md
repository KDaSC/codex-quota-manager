# 想法收件箱

本机 macOS 原型：保存原话，选择自动整理后，用现有 ChatGPT 登录生成中文草稿。记录、列表、暂停和定时判断由本机代码完成，不需要模型额度或 API key；AI 整理使用账户的 Codex 额度。

## 直接使用

可运行应用位于 `~/Library/Caches/IdeaInboxDevelopment/想法收件箱.app`。工程的 `应用/想法收件箱.zip` 保留一份应用包。工程所在的 File Provider 目录会给 .app 自动添加 FinderInfo，使签名验证失败，因此应用放在本机缓存；没有安装到 Applications 或设置登录项。

输入原话，点击“保存想法”（⌘↩）。默认只记录；勾选自动整理后，新记录进入队列，原话会发送给已登录的 Codex，并使用账户额度。应用每次启动都会先通过本机 Codex App Server 做只读握手，读取登录状态、模型目录和额度；不会发送想法或请求模型生成内容。下载或解压阶段还没有运行中的应用，握手会在首次打开时进行。菜单栏灯泡提供打开窗口和暂停入口。应用运行期间有待办才检查；退出后不继续轮询。没有全局快捷键。

打包 ZIP 不携带开发机路径；首次运行默认将数据保存在 `~/Library/Application Support/IdeaInbox`。本机开发版继续使用工程 `运行数据/`，以保留原有开发记录。数据目录保存想法、队列状态、额度快照和你明确选中文本文件的本机副本。一般使用不必调整；需要查看或更改时，在应用菜单打开“设置…”，数据目录选择和访达按钮都在“本机数据”中。更改目录会切换到另一个位置，不会搬走旧记录。`state.json` 为当前状态，`state.backup.json` 为上一次快照；草稿另存为 `tasks/任务UUID/草稿.md`。请在应用退出后备份整个数据目录。

每条自动整理任务都记录草稿位置：默认保存到收件箱数据目录，也可用“选择文件夹”指定项目或其他文件夹，已完成任务可从详情中在访达显示草稿。这个文件夹只作输出位置；Codex 在单独的空工作目录中运行，不把项目文件夹作为工作区。使用“从访达添加”可主动选取最多 8 个 UTF-8 文本文件（总计约 120 KB）；程序只读取这些文件，原路径不会保存，原文件不会修改。未勾选自动整理时，选中文件仅以私有权限保存在本机；勾选后，文件文本会和原话一起发给 Codex。整理时，原话作为本回合请求，附件只作参考资料，附件里的指令不会被当成本回合要求。取消文件选择不会影响原文件。

自动工作当前限定为“目标、约束、下一步”文本草稿，显式请求 GPT-6.1 Sol / Medium。若 Codex 已生成草稿但原定目录不可写，已读回的草稿会先保存在本机记录中；可在详情中另选位置保存，不会再次调用模型。通用开发任务、完整模型路由和归入其他项目待后续开发。本工程复杂开发判断建议 Sol / High，普通实现可用 Medium；未宣称改变当前聊天设置。

## 额度与恢复规则

- 任一适用窗口剩余 ≤10% 时等待。未知、异常、过期额度不派发；派发前重新核验，快照最长有效 60 秒。
- 有待办时默认 15 分钟补查；已知重置后 60 秒复查，仍以真实读数决定能否继续。网络失败按 2、5、15 分钟、之后每小时退避。
- 唤醒后丢弃内存额度并复查；派发前收到新的额度通知使旧观察失效，账户变化暂停整理。
- 并发 1，数据目录独占锁。重启时发送中/运行中的任务标为不确定，不自动重发；未核对操作占用全局执行槽。已有回合的读回失败只允许核对，不重新派发；明确拒绝开始或明确失败的限额回合才等待额度。
- 自有 App Server 子进程及自有线程，每进程请求禁用工具等能力，read-only 沙箱、never 审批；不改账户或全局配置，不接管其他聊天。

## 开发与命令行

需要本机 Swift 和 Codex；无需第三方依赖。

```sh
swift build -j 1
swift run -j 1 idea-inbox-check
python3 -m unittest discover -s tests -v
python3 scripts/build_app.py
.build/debug/idea-inbox --root ./运行数据 capture --text '我的原始想法'
.build/debug/idea-inbox --root ./运行数据 list
.build/debug/idea-inbox --root ./运行数据 inspect
```

自动记录加 `--auto`；`work` 每次最多处理一条待办。`stop` / `allow` 是总暂停/允许，`cancel UUID` 取消未运行任务。CLI 与应用不能同时打开同一数据目录。`simulate UUID --primary-used 95 --secondary-used 20` 只模拟决策。
